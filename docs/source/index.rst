Canon PIXMA MG3620 Wireless Setup
================================

Canon PIXMA MG3620 wireless setup connects your printer to a WiFi router so compatible computers and mobile devices can print without a USB cable. Setup involves preparing the printer, connecting it to your network, and adding it to each device you want to use.

This guide explains the main connection methods, installation checks, and troubleshooting steps. It is an independent guide and is not affiliated with Canon.

Before You Begin
----------------

Switch on the printer and allow it to finish starting. Check that its initial cartridge installation is complete, paper is loaded, and no error requires attention.

Have these items ready:

* Your WiFi network name and password.
* A computer or phone connected to your home network.
* A compatible setup application for the MG3620.
* Access to your router if using WPS.

Place the printer close enough to the router to receive a reliable signal during installation.

Choose a Wireless Setup Method
-------------------------------

You can configure the printer through a compatible setup application or use WPS when the router offers it.

The MG3620 does not have a touchscreen for entering a WiFi password. Follow the model-specific instructions in the setup application or printer manual rather than using a button sequence intended for another model.

Application-Assisted Setup
~~~~~~~~~~~~~~~~~~~~~~~~~~

The setup application guides you through preparing the printer for wireless connection, choosing the network, and completing installation.

This is useful when your router does not have WPS or when you prefer guided setup.

WPS Connection
~~~~~~~~~~~~~~

WPS allows compatible routers and printers to establish a wireless connection without manually entering the network password.

The feature must be available and enabled on your router. Check the router's controls carefully so you do not press its reset button.

Prepare Your WiFi Network
-------------------------

Check that the router provides a compatible 2.4 GHz wireless network for the MG3620.

Your computer or phone may use a different wireless band if the router allows communication between devices on the same local network.

Avoid a guest network that isolates connected devices. Confirm the WiFi password before starting, including capital letters and special characters.

How to Connect Canon MG3620 to WiFi
-----------------------------------

Open the Setup Application
~~~~~~~~~~~~~~~~~~~~~~~~~~

Use a trusted installation package or application intended for the Canon PIXMA MG3620 and your operating system.

Choose the option to configure a wireless connection. Keep the printer switched on and follow the on-screen instructions.

Prepare the Printer for Connection
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

When prompted, use the printer's controls to enter the required wireless setup mode.

Follow the instructions for this model exactly. Do not hold buttons for an arbitrary length of time or continue if the indicator pattern does not match the instructions.

Choose Your Network
~~~~~~~~~~~~~~~~~~~

Select your home WiFi network and enter its password when requested.

During setup, the computer or phone may temporarily communicate directly with the printer. Continue through the prompts until the application confirms that network configuration is complete.

Finish Installation
~~~~~~~~~~~~~~~~~~~

Allow the application to detect the printer and finish adding it.

Afterward, confirm that your computer or phone is connected to the home network. Print a short document to test communication.

Canon MG3620 WPS Setup
----------------------

If you choose WPS, follow the MG3620's WPS procedure to prepare the printer, then activate the router's WPS function within the specified connection window.

Wait for the printer to confirm its connection before continuing.

If WPS fails, check that the router allows WPS connections. You can use application-assisted setup instead of repeatedly attempting the same procedure.

A successful WPS connection joins the printer to the network. You may still need to add it to your computer separately.

Add Canon MG3620 to Windows
---------------------------

Once the printer is connected to WiFi, open your computer's printer settings.

On Windows 11, open Settings, select Bluetooth & devices, and choose Printers & scanners.

On Windows 10, open Settings, select Devices, and choose Printers & scanners.

Choose the option to add a printer. Select the MG3620 when it appears and follow the prompts.

Canon MG3620 Driver Installation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Windows may install a suitable driver automatically. Additional software may be needed for scanning, maintenance, or particular printing options.

Choose software intended for the MG3620 and your Windows version. Avoid unrelated driver updater applications.

If several printer entries appear, select the one associated with your wireless connection.

Connect Canon MG3620 to a Mac
-----------------------------

Connect the Mac to the same local network as the printer.

Open the Mac's printer settings and choose the option to add a printer. Select the MG3620 from the available devices.

Use AirPrint when available for your configuration, or select compatible printer software.

Complete the installation, open a document, and select the printer in the print dialog. Check the paper settings and print one page.

Canon MG3620 Wireless Setup on a Phone
--------------------------------------

Use a compatible Canon mobile application to configure or discover the printer.

Follow the application's instructions and review any permissions needed for local device discovery.

Once setup is complete, connect the phone to the same local network as the printer.

Open a document or photo, choose the printing option, and select the MG3620. Review the paper size and media settings before printing.

Canon MG3620 Setup Without a CD
-------------------------------

A CD is not always necessary for installation.

A compatible computer may add the printer through its built-in printer settings. If additional software is needed, use a trusted package that matches your model and operating system.

Installing the printer for basic printing does not always configure every scanning feature. Test scanning separately after printing works.

Canon MG3620 Not Connecting to WiFi
-----------------------------------

Check the Network Name and Password
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Confirm that you selected the correct network and entered its current password.

If you recently changed the password, the printer's previously saved details will no longer work.

Check Wireless Compatibility
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Make sure a compatible 2.4 GHz network is available.

A 5 GHz-only network cannot provide the printer's required wireless connection.

Improve the Signal
~~~~~~~~~~~~~~~~~~

Move the printer closer to the router while testing.

Walls, enclosed cabinets, and interference can make wireless communication unreliable.

Restart and Try Again
~~~~~~~~~~~~~~~~~~~~

Restart the printer and the device running setup.

Restart the router if other devices also experience network problems. Allow it to finish starting before repeating installation.

Reconnect After Changing Your Router
------------------------------------

A new router may use a different WiFi name, password, or network configuration.

Run the Canon MG3620 wireless setup process again using the current network details.

If the printer connects but your computer cannot print, check whether the existing printer entry refers to the old configuration. Remove and add that entry again if necessary.

Reset only the printer's network settings when the model's instructions call for it. A reset removes saved wireless information and requires setup again.

Canon MG3620 Connected but Not Printing
---------------------------------------

Check the printer selected in your application. An old USB entry or duplicate installation may still be selected.

Open the print queue and remove failed documents. Resume printing if it is paused.

Check that the printer has paper and displays no error.

Try another device. If it prints successfully, focus on the affected computer's queue, printer entry, and software.

Scan After Wireless Installation
--------------------------------

Place a document on the scanner glass and open a compatible scanning application.

Select the MG3620 scanner associated with your network connection.

Scan one page and check the saved file. If printing works but scanning does not, review scanner selection and the required scanning software.

Frequently Asked Questions
--------------------------

Can I complete Canon MG3620 wireless setup without WPS?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Yes. Use a compatible setup application to configure the printer's network connection.

Does the MG3620 need a USB cable for wireless printing?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

A USB cable is not required for everyday printing once the wireless connection is configured.

Can more than one computer use the printer?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Compatible computers on the same local network can usually add the printer separately.

Why does the printer disappear after a router change?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

It may still contain the previous network details, or the computer may use an outdated printer entry. Reconnect the printer and check the installation.

How do I confirm setup is complete?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Print a small document from your chosen device. For a complete multifunction check, scan one page and open the saved file as well.

Complete Your First Wireless Print
----------------------------------

Select the MG3620 in your application's print dialog and send a short document.

Once the page prints correctly, continue with your usual files. Keep a note of the connection method so reconnecting is easier after future network changes.
